# 支持文档

生效日期：2026-02-22

**支持范围**
- 课表与待办功能使用问题
- 通知、Siri 与搜索、小组件、实时活动相关问题
- 账户与数据：本应用不提供账号体系，数据仅存储在设备本地

**我们无法提供的支持**
- 设备系统故障或第三方应用问题
- 与系统设置、网络环境相关的非应用自身问题

**常见问题（待补充）**
- 如何开启或关闭通知？
- 如何使用 Siri 快捷指令？
- 如何备份或迁移数据？
